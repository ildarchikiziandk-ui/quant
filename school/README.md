# Школа — электронный дневник (school.nvra.ru)

Отдельное приложение: своя база (`school/data/school.db`), свои пользователи и вход, своя служба `nuvora-school`
и своё Android-приложение (`school/android`, пакет `ru.nvra.school`). С Nuvora общий только сервер.

- **Учитель** (один, логин по умолчанию `rubl`): ученики с логинами и паролями, предметы, недельное расписание и звонки,
  оценки 1–5 по четвертям (контрольные весят вдвое), поведение, домашние задания, переписка с каждым учеником.
- **Ученик**: главная (уроки на сегодня с ДЗ, новые оценки), оценки со средним баллом, поведение, задания с отметкой
  «сделано», расписание на неделю, переписка с учителем.
- **Приложение**: сайт внутри приложения + уведомления о новых оценках, заданиях и сообщениях (раз в ~15 минут),
  обновление без GitHub (`/download/school.apk`). iPhone — «На экран Домой».

Установка на сервер (после A-записи `school` → IP сервера): `sudo bash /opt/nuvora/deploy/school.sh`.
Пароль учителя скрипт спросит сам — в репозитории его нет. Локально: `uvicorn school.app:app --port 8010`.
