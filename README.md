# ✦ Nova

Социальная сеть на FastAPI: лента, истории, рилсы, мессенджер, звонки, группы и геймификация.
Раньше проект назывался **Quant**. Имя бренда задаётся одной переменной `BRAND_NAME`: её подставляют все страницы, письма, push-уведомления и PWA-манифест.

## Быстрый старт

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # задайте SECRET_KEY и остальное
uvicorn main:app --reload     # http://localhost:8000
pytest                        # 23 интеграционных теста
```

На сервере запуск описан в `Procfile`. Миграции выполняются автоматически при старте: недостающие таблицы и колонки добавляются, существующие данные не трогаются. Работает и с PostgreSQL, и с SQLite.

## Структура

```
main.py            — приложение, middleware (CSRF, заголовки безопасности), страницы ошибок
config.py          — все настройки из окружения / .env (бренд, секреты, лимиты)
auth.py            — bcrypt, JWT + серверные сессии, TOTP 2FA
migrations.py      — автодобавление колонок, сиды достижений и заданий
models.py          — модели SQLAlchemy
deps.py            — рендер шаблонов с общим контекстом, фильтры Jinja
services/          — загрузки, почта, push, ранжирование ленты, правила приватности, геймификация, rate limit
routers/           — маршруты по разделам (posts, profile, messages, groups, stories, reels, admin, calls…)
templates/         — страницы; общие макросы в templates/partials
static/            — css/app.css, js/app.js, sw.js, иконки
tests/             — pytest
```

## Возможности

**Лента и посты:** вкладки «Для вас» (ранжирование по вовлечённости и свежести) / «Подписки» / «Свежее» / «Медиа», бесконечная прокрутка. Карусели до 10 фото и видео, опросы со сроком действия, реакции эмодзи, «киты», репосты и цитаты, закладки, редактирование, закреп в профиле. Видимость «только подписчикам», отключение комментариев, отложенная публикация, черновики. Подсветка @упоминаний, #тегов и ссылок, автодополнение при наборе. Статистика поста: просмотры, ER, кто лайкнул.

**Комментарии:** ветки ответов, лайки, закрепление автором, удаление автором поста.

**Профиль:** обложка, вкладки «Посты / Ответы / Медиа / Рилсы / Лайки», «Актуальное» из историй, общие подписчики, метка «подписан на вас», QR-код профиля, статистика для владельца, местоимения, соцсети.

**Приватность:** закрытый профиль с заявками на подписку, блокировка (работает в обе стороны), скрытие автора из ленты, удаление подписчика, близкие друзья, скрытие лайков и статуса «онлайн», выбор, кто может писать.

**Истории:** фото, видео и текст на цветном фоне, аудитория «близкие друзья», реакции, ответ в личку, список просмотревших, «Актуальное», пауза и навигация с клавиатуры.

**Рилсы:** вертикальная лента со snap-прокруткой, автовоспроизведение, лайки, комментарии, счётчик просмотров.

**Мессенджер:** голосовые, видеокружки, фото, файлы, вставка картинок из буфера, ответы, пересылка, реакции, редактирование, закреп сообщения, исчезающие сообщения, «печатает…», статусы прочтения ✓✓, поиск по чату и по всем сообщениям, закреп и отключение звука для чатов.

**Группы:** ссылки-приглашения, админы, исключение участников, передача владения при выходе, вложения.

**Звонки:** аудио и видео через WebRTC, уведомление о входящем звонке на любой странице, принятие и отклонение, история звонков, пропущенные приходят в уведомления. TURN-сервер настраивается через окружение.

**Геймификация:** очки, уровни, стрики, ежедневные задания, челленджи недели, розыгрыш Plus по билетам, рейтинг (очки / неделя / стрики / уровни), 21 достижение.

**Уведомления:** фильтры по типам, настройка по видам, web-push, живые счётчики.

**Аккаунт и безопасность:** bcrypt (старые sha256-хэши обновляются при входе), сессии на сервере со списком устройств и выходом из всех сеансов, 2FA через приложение-аутентификатор, подтверждение email, сброс пароля, смена логина и email, экспорт данных, полное удаление аккаунта. Rate limit на вход, регистрацию, посты и сообщения. Защита от CSRF, экранирование XSS, заголовки безопасности.

**Админ-панель:** дашборд с графиком, поиск пользователей, блокировки с причиной, роли, подарок Plus и очков, жалобы на посты и пользователей (со скриншотами), заявки на верификацию, ответы в поддержку, стоп-слова (автоцензура), промокоды, объявление на всех страницах, челленджи, розыгрыш, журнал действий модераторов.

**Прочее:** светлая, тёмная и системная тема, акцентный цвет и размер шрифта, PWA с офлайн-страницей, горячие клавиши (`?` — справка), адаптивная мобильная версия.
