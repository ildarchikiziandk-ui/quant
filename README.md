# ✦ Nuvora

Социальная сеть на FastAPI: лента, истории, мессенджер, группы и геймификация.
Раньше проект назывался **Quant**. Имя бренда задаётся одной переменной `BRAND_NAME`: её подставляют все страницы, письма, push-уведомления и PWA-манифест.

## Быстрый старт

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # задайте SECRET_KEY и остальное
uvicorn main:app --reload     # http://localhost:8000
pytest                        # 41 интеграционный тест
```

На сервере запуск описан в `Procfile`. Миграции выполняются автоматически при старте: недостающие таблицы и колонки добавляются, существующие данные не трогаются. Работает и с PostgreSQL, и с SQLite.

## Структура

```
main.py            — приложение, middleware (CSRF, заголовки безопасности), страницы ошибок
config.py          — все настройки из окружения / .env (бренд, секреты, лимиты)
auth.py            — bcrypt, JWT + серверные сессии, TOTP 2FA
migrations.py      — автодобавление колонок, сиды достижений и заданий
models.py          — модели SQLAlchemy
deps.py            — рендер шаблонов с общим контекстом, фильтры Jinja
services/          — загрузки, почта, push, ранжирование ленты, правила приватности, геймификация, rate limit
routers/           — маршруты по разделам (posts, profile, messages, groups, stories, admin…)
templates/         — страницы; общие макросы в templates/partials
static/            — css/app.css, js/app.js, sw.js, иконки
tests/             — pytest
```

## Возможности

**Лента и посты:** вкладки «Для вас» (ранжирование по вовлечённости и свежести) / «Подписки» / «Свежее» / «Медиа», бесконечная прокрутка. Карусели до 10 фото и видео, опросы со сроком действия, реакции эмодзи, «киты», репосты и цитаты, закладки, редактирование, закреп в профиле. Видимость «только подписчикам», отключение комментариев, отложенная публикация, черновики. Подсветка @упоминаний, #тегов и ссылок, автодополнение при наборе. Статистика поста: просмотры, ER, кто лайкнул.

**Комментарии:** ветки ответов, лайки, закрепление автором, удаление автором поста.

**Профиль:** обложка, вкладки «Посты / Ответы / Медиа / Лайки», «Актуальное» из историй, общие подписчики, метка «подписан на вас», QR-код профиля, статистика для владельца, местоимения, соцсети.

**Приватность:** закрытый профиль с заявками на подписку, блокировка (работает в обе стороны), скрытие автора из ленты, удаление подписчика, близкие друзья, скрытие лайков и статуса «онлайн», выбор, кто может писать.

**Истории:** фото, видео и текст на цветном фоне, аудитория «близкие друзья», реакции, ответ в личку, список просмотревших, «Актуальное», пауза и навигация с клавиатуры.

**Мессенджер:** голосовые, видеокружки, фото, файлы, вставка картинок из буфера, ответы, пересылка, реакции, редактирование, закреп сообщения, исчезающие сообщения, «печатает…», статусы прочтения ✓✓, поиск по чату и по всем сообщениям, закреп и отключение звука для чатов.

**Группы:** ссылки-приглашения, админы, исключение участников, передача владения при выходе, вложения.

**Геймификация:** очки, уровни, стрики, ежедневные задания, челленджи недели, розыгрыш Plus по билетам, рейтинг (очки / неделя / стрики / уровни), 20 достижений.

**Уведомления:** фильтры по типам, настройка по видам, web-push, живые счётчики.

**Аккаунт и безопасность:** bcrypt (старые sha256-хэши обновляются при входе), сессии на сервере со списком устройств и выходом из всех сеансов, 2FA через приложение-аутентификатор, подтверждение email, сброс пароля, смена логина и email, экспорт данных, полное удаление аккаунта. Rate limit на вход, регистрацию, посты и сообщения. Защита от CSRF, экранирование XSS, заголовки безопасности.

**Админ-панель:** дашборд с графиком, поиск пользователей, блокировки с причиной, роли, подарок Plus и очков, жалобы на посты и пользователей (со скриншотами), заявки на верификацию, ответы в поддержку, стоп-слова (автоцензура), промокоды, объявление на всех страницах, челленджи, розыгрыш, журнал действий модераторов.

**Прочее:** светлая, тёмная и системная тема, акцентный цвет и размер шрифта, PWA с офлайн-страницей, горячие клавиши (`?` — справка), адаптивная мобильная версия.

## Рекомендации

На главной две вкладки: «Подписки» и «Рекомендации». Пост создаётся на отдельной странице `/create`.

Рекомендации строит модель `services/recommend.py`:
1. **Профиль интересов.** Из лайков, реакций, китов, комментариев, закладок и репостов собираются веса авторов, хэштегов и слов. Свежие действия весят больше: период полураспада 30 дней. Кнопка «Не интересно» в меню поста даёт отрицательный вес.
2. **Оценка поста.** Складывается из похожести на интересы, вовлечённости с поправкой на возраст поста, свежести и небольшой доли нового. Уже просмотренные, лайкнутые и «неинтересные» посты штрафуются.
3. **Разнообразие.** Один автор или одна тема не идут подряд.
4. **Объяснение.** Над рекомендацией можно показывать причину, например «Вам нравится #котики».

## Расширенные настройки

`services/prefs.py` — реестр из 74 дополнительных настроек. Они хранятся в JSON-колонке `User.prefs` и распределены по разделам:

| Раздел | Что настраивается |
|---|---|
| Лента | работа рекомендаций, фильтры, отображение, боковая панель |
| Приватность | кто комментирует и упоминает, репосты, скрытые списки, режим инкогнито, отчёты о прочтении |
| Уведомления | дополнительные типы, тихие часы, скрытый текст в push |
| Сообщения | отправка по Enter, вид сообщений |
| Оформление | компактный режим, углы, аватарки, шрифт, часовой пояс |
| Доступность | анимации, контраст, крупные кнопки, горячие клавиши |

Каждая настройка реально работает: серверные проверяются в коде, браузерные применяются через CSS-класс `p-<ключ>` на `<html>` или поведение в `app.js`.

## Часовые пояса

`services/timezones.py` содержит 61 город: все пояса России и соседних стран плюс крупные мировые города. Каждый город — отдельный пункт, даже если смещение совпадает. Например, Новосибирск (`Asia/Novosibirsk`) и Красноярск (`Asia/Krasnoyarsk`) оба UTC+7, но в списке это разные пункты.

В базе время хранится в UTC. В поясе пользователя показываются:
- сообщения;
- посты;
- опросы;
- отложенные публикации;
- блокировки;
- тихие часы.

Пояс определяется браузером при регистрации. В настройках есть кнопка «Определить по устройству».

## Собственная модель модерации

`services/moderation.py` — своя лёгкая нейромодель, которая проверяет каждый новый пост, репост с комментарием и комментарий:
- **токсичность** (оскорбления, мат, агрессия) — логистическая регрессия на хэшированных символьных n-граммах и словах. Модель понимает маскировку: «х.у.й», «н а х у й», латинские буквы вместо русских, «бл*ть», «дуууурак»;
- **спам** — правила: ссылки, телефоны, «заработок», «пиши в лс», капс.

Модель весит ~300 КБ (`ml/toxicity_ru.bin`, веса в int8), работает на чистом Python без numpy и видеокарты, тратит ~0,04 мс на текст.
На отложенной выборке AUC 0,98. При пороге 0,7 точность ~99%, полнота ~80%. При пороге 0,93 ложных срабатываний 0%.

Что происходит:
- оценка от `MOD_FLAG_THRESHOLD` (0,7) — материал попадает в админку, вкладка «🤖 Нейромодерация»;
- оценка от `MOD_HOLD_THRESHOLD` (0,93) — пост скрывается до решения модератора, автору приходит уведомление.

Сама модель ничего не удаляет. Выключить её можно через `MODERATION_ENABLED=0` в `.env`.

Переобучение (numpy и scipy нужны только здесь):
```bash
curl -O https://raw.githubusercontent.com/s-nlp/russe_detox_2022/main/data/input/train.tsv
curl -O https://raw.githubusercontent.com/s-nlp/russe_detox_2022/main/data/input/dev.tsv
pip install numpy scipy && python tools/train_moderation.py train.tsv dev.tsv
```
Данные: RUSSE Detox 2022 (s-nlp). Это токсичные комментарии и их вежливые перефразы, размеченные людьми.

## Ещё функции

**Вопросы.** Анонимные и обычные вопросы в профиль, как на ask.fm.
- Входящие лежат в `/questions`, ответы показываются публично на `/ask/<логин>`.
- Ответ можно продублировать в ленту.
- Вопросы проверяет модель модерации.
- В настройках задаётся, кто может спрашивать и разрешены ли анонимные вопросы.

**Подписка на темы.** Кнопка «Подписаться на тему» на странице хэштега. Посты с этой темой попадают во вкладку «Подписки» и сильнее влияют на рекомендации.

**Мероприятия.** Раздел `/events`:
- событие с датой (в часовом поясе автора), местом и описанием;
- кнопки «Пойду» и «Интересно», списки участников;
- вкладки «Скоро», «Мои» и «Прошедшие».

**Подарки за очки.** 12 подарков стоимостью от 10 до 500 очков, с подписью, можно анонимно. Подарки видны в профиле. Уровень от трат не падает: потраченные очки учитываются отдельно в `spent_points`.

**Коллекции закладок.** Папки вроде «Рецепты» или «Смешное». Пост в нужную папку переносится прямо со страницы закладок.

**Викторины.** Опрос с правильным ответом:
- за верный ответ +10 очков;
- после голосования отмечается ✅ / ❌;
- есть достижение «Эрудит».

**Приглашения.** Личная ссылка `/invite/<логин>`:
- за каждого зарегистрировавшегося друга +100 очков, не больше 5 наград в сутки;
- достижение «Пригласивший»;
- кнопки «Поделиться» в Telegram, WhatsApp и ВКонтакте.

**Интересы.** До 10 тегов в профиле. Страница `/interests/<тег>` показывает людей с этим интересом. Интересы учитываются в рекомендациях.

**«Возможно, вы знакомы».** Друзья друзей с числом общих знакомых и люди с общими интересами. Показываются в «Обзоре» и в боковой панели.

**Поиск с фильтрами.** Только с фото, из подписок, за сутки, неделю, месяц или год.

**«В этот день».** Ваши посты этого дня из прошлых лет, на главной появляется карточка.

**Время чтения.** У длинных постов показывается, например, «~3 мин».

**Новые достижения.** «Пригласивший», «Эрудит», «Щедрая душа», «Открытая книга», «Организатор».

## Бесплатный хостинг с доменом DuckDNS

1. Возьмите бесплатный сервер: Oracle Cloud Always Free (Ubuntu 22.04/24.04), откройте в нём порты 80 и 443. Подойдёт и свой компьютер дома, если пробросить эти порты на роутере.
2. На [duckdns.org](https://www.duckdns.org) войдите, создайте поддомен (например, `quantru`) и скопируйте токен.
3. На сервере:
   ```bash
   git clone -b claude/happy-wozniak-vvu5w4 https://github.com/ildarchikiziandk-ui/quant.git
   sudo bash quant/deploy/install.sh quantru ВАШ_ТОКЕН      # DuckDNS
   sudo bash quant/deploy/install.sh nvra.ru                # или свой домен (A-записи @ и www → IP сервера)
   ```
   Скрипт привяжет домен к IP сервера (и будет обновлять его каждые 5 минут), установит приложение в `/opt/nuvora`, создаст `.env` со случайным `SECRET_KEY`, запустит службу `nuvora` и поднимет HTTPS через nginx и Let's Encrypt.
4. Сайт будет доступен на `https://quantru.duckdns.org`.

Обновление: `sudo bash /opt/nuvora/deploy/update.sh`. Бэкап: `sudo bash /opt/nuvora/deploy/backup.sh`. Логи: `journalctl -u nuvora -f`.

## Android-приложение

Исходники лежат в `android/`: это приложение на WebView, которое открывает сайт. Внутри приложения работают:
- вход и cookies;
- загрузка фото и файлов;
- голосовые сообщения и видеокружки;
- скачивание файлов;
- кнопка «назад»;
- уведомления о новых сообщениях (сервер проверяется примерно раз в 15 минут).

APK собирается автоматически через GitHub Actions (`.github/workflows/android.yml`) при каждом изменении в `android/` и выкладывается в [Releases](https://github.com/ildarchikiziandk-ui/quant/releases/latest).
Прямая ссылка на последнюю версию: https://github.com/ildarchikiziandk-ui/quant/releases/latest/download/Nuvora.apk

Чтобы собрать APK для другого домена, поменяйте `SITE_URL` в workflow и хосты в `AndroidManifest.xml`.
Ключ подписи `android/nuvora.keystore` лежит в репозитории: с ним обновления ставятся поверх старой версии. Пароль ключа можно переопределить переменной `KEYSTORE_PASSWORD`.
